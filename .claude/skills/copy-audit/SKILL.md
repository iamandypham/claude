# copy-audit: persuasion self-audit (Andy, 26 Oct 2026)

Andy, 26 Oct 2026: "create a checklist and tell it to audit its output against it the checklist... Do it RIGHT NOW."

Every copy agent runs this on its own output before delivery. It sits after the draft and before the Jeremy review and Andy.

## Steps
1. Draft as usual (messaging bank first, your format's own skill such as reel-scripts, X rules, etc.).
2. Open `checklist.md` in this folder. Run Part A (guardrails) first. Any FAIL: fix it before anything else.
3. Run the 15 principles in Part B. Mark each PASS, GAP or N/A (use the "Which items apply where" table; give the reason for N/A).
4. For each GAP, quote the line and write the fix. Apply the fixes, then re-run the items you touched. Don't loosen an item to get a PASS.
5. Fixes may only use `USE`/`SOURCED` bank lines or Andy's own words. If a GAP can only be closed with a new claim or number, leave it as GAP and list it as a question for Andy.
6. Deliver the copy with a short audit block (below). For files, save it as `audit.md` next to the copy.

## Audit block
```
Copy audit (copy-audit skill, <date>)
Guardrails: G1-G8 pass | <any FAIL and the fix>
Principles: <n> PASS, <n> GAP fixed, <n> GAP open, <n> N/A
| # | principle | verdict | line | fix |
Open for Andy: <questions or "none">
```
Keep it out of anything Andy reads aloud (teleprompter files) or posts.

## Notes
- The checklist is a tool, not a quota. A 4-frame story won't use all 15; N/A with a reason is fine.
- The guardrails override the post where they conflict (it says associations needn't be true; ours must be).
- If Andy corrects a line that passed the audit, log it in `/mnt/project-files/meta/flywheel/lessons.md` and propose a checklist change.
- Shared copy for non-Claude agents: `/mnt/project-files/content/persuasion-checklist-2026-10-26/checklist.md` and the Slite page "Copy persuasion checklist".
